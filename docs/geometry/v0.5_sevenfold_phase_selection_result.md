```text

```


rotation test is:


```text

```

The four candidate `{7/2}` star geometries are intrinsically metric-equivalent
within floating-point tolerance.

scaffold selects a unique phase.


selection.

## Final Phase 5F interpretation

Phase 5F establishes two complementary results.

### Construction-grammar result

```text
GRAMMAR_UNDERDETERMINED
```

The generated 28-point scaffold contains four C4-equivalent admissible
seven-point phases.

The audited grammar does not uniquely select their orientation.

### Figure 14 source-consistency result

```text
phase 3 is the strongest source-consistency match
```

under the frozen 14-correspondence, zero-refit comparison.

Its best correspondence reproduces the currently implemented sequence:

```text
7, 11, 15, 19, 23, 27, 3
```

with:

```text
RMS = 0.03102360563200974 u
```

while the next-best phase has:

```text
RMS = 1.5480658592729957 u
```

The correct combined statement is therefore:

```text
The construction grammar generates four symmetry-related seven-point phase
candidates and does not independently select one.  When those four frozen
candidates are compared descriptively with the already calibrated Figure 14
source endpoints, phase 3 is strongly preferred and its optimal cyclic
correspondence is exactly the phase-3 ordering used by NJG_MICHELL.
```

The second statement must not be used to rewrite the first.
