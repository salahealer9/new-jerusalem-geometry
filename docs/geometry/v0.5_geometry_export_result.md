# v0.5 NJG_MICHELL machine-readable geometry export result

## Status

Phase 5D implements a deterministic machine-readable numerical geometry export
for the complete `NJG_MICHELL` generative composite.

The geometry exporter is a pure downstream view of an already constructed
`MichellComposite`.

It does not reconstruct geometry, consume source-plate calibration data, or
derive historical evidence classifications.

## Architecture

The completed architecture is:

```text
build_michell_composite(unit)
          |
          v
    MichellComposite
          |
          +------------------------+
          |                        |
          v                        v
 numerical geometry         provenance manifest
          |                        |
          +-----------+------------+
                      |
                   object_id
                      |
                      v
                     SVG
````

The geometry and provenance exports are parallel downstream representations of
the same supplied composite.

Neither export is used to generate the other.

## Evidence boundary

The geometry export contains no:

```text

source_status
relation_type
node_type

```

These fields remain exclusively within the provenance/evidence representation.

The geometry exporter therefore describes numerical geometry without silently
duplicating or flattening historical evidence classifications.

## Determinism

Repeated serialization of an identical supplied `MichellComposite` is
byte-identical.

The canonical Phase 5D SHA-256 is:

```text
19e22356378d581a2adb35c8f8b8ee0237f61ab365d8cbc05abc378568e3b6cb
```

Numerical values are stored using Python's deterministic JSON float
serialization without presentation-style coordinate rounding.
