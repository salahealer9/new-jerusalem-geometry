# v1.0 Plato–Michell whorl visual capstone

## Status

Phase 10G adds the final deterministic visual capstone for the frozen
Plato–Michell numerical reconstruction established in Phase 10E.

It adds no new source extraction, numerical fitting, optimisation, permutation
search, scale estimation, or historical inference.

The generated figure is:

```text
figures/generated/v1.0_plato_michell_whorl_capstone.svg
```

## Upstream dependency

The sole numerical/geometric input is:

```text
data/analysis/njg_michell_v1_0/plato_michell_whorl_reconstruction.json
```

The rendering path is:

```text
frozen Phase 10E reconstruction JSON
               |
               v
plato_michell_whorl_capstone_to_svg()
               |
               v
v1.0_plato_michell_whorl_capstone.svg
```

The renderer does not reconstruct the historical argument independently and
does not search for an arrangement.

The application-boundary generation script reads the frozen JSON and passes it
to the pure SVG renderer.

## Rendered geometry

The figure represents the central shaft and eight whorls as exact radial bands.

For each whorl, the SVG annulus is drawn from the cumulative inner radius to the
cumulative outer radius encoded in Phase 10E.

The frozen centre-out chain is therefore visualised directly:

```text
shaft radius
4

centre-out whorl widths
18, 12, 27, 9, 24, 8, 6, 36

cumulative radii
4, 22, 34, 61, 70, 94, 102, 108, 144
```

The displayed scaled values are obtained only from the frozen Phase 10E scale
factor and scaled cumulative-radius array.

## Highlighted boundaries

Three boundaries receive visual emphasis:

1. the first cumulative boundary, corresponding to the printed 3960
   Earth-radius / Magnesia value;
2. the second cumulative boundary, corresponding to the printed 6120
   New Jerusalem outer-circle value;
3. the full outer radius, corresponding to Michell's printed/canonical 25920
   precessional value.

These annotations are presentation labels. They do not participate in the
geometry calculation.

## Determinism

Phase 10G inherits the Phase 10E zero-search boundary:

```text
free parameters          0
nearest-match choices    0
optimisations            0
permutation searches     0
scale fits               0
```

Fixed canvas dimensions, colours, typography, label angles, and panel positions
are presentation choices only. They do not alter the mathematical geometry.

The exact annular radii and widths are computed from the frozen reconstruction
values.

## Machine-readable SVG semantics

The SVG exposes deterministic identifiers and `data-*` attributes for testing.

Examples include:

```text
#shaft
#whorl-8 ... #whorl-1
#boundary-1 ... #boundary-8
#first-cumulative-correspondence
#second-cumulative-correspondence
#outer-boundary-correspondence
```

Whorl elements encode their whorl number, width, inner radius, outer radius, and
scaled outer radius.

The root SVG records the upstream audit phase, provenance class, and number of
free parameters.

## Reproduction

Generate the figure with:

```bash
python scripts/generate_v1_0_plato_michell_whorl_capstone.py
```

Then run:

```bash
pytest -q tests/test_v1_0_plato_michell_whorl_capstone.py
```

The committed generated SVG is required to equal the renderer output byte for
byte after the generator's terminating newline is added.
