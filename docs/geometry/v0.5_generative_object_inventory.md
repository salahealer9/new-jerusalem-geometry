# v0.5 canonical generative object inventory

## Status

Phase 5A identifies `MichellComposite` as the canonical complete generative
geometry object for v0.5.

No second geometry container is introduced.

Downstream rendering, serialization, and provenance layers must consume the
existing `MichellComposite` and must not independently reconstruct geometric
elements.

## Canonical object

The object is built by:

```python
build_michell_composite(unit=1.0)
````

The caller supplies only the scale unit.

The resulting `MichellComposite` contains:

* `core`

  * normalized dimensions;
  * origin;
  * Earth circle;
  * construction circle;
  * Earth square;
  * four cardinal Moon circles;
* `moon_groups`

  * four source-described groups of three Moon circles;
* `wall_reconstruction`

  * twelve Moon circles;
  * twelve polar-pivot wall lines;
  * twelve wall vertices;
* `sevenfold`

  * seven Method-1 points;
* `fourteenfold`

  * fourteen points from the primary and reciprocal constructions;
* `four_triangle_angles_radians`

  * twenty-eight independently generated angular marks;
* `scaffold`

  * twenty-eight role-labelled scaffold points;
* `scaffold_heptagram_candidate`

  * seven vertices selected from the scaffold;
* `four_triangle_scaffold_max_mismatch_radians`

  * numerical closure diagnostic between the independently generated
    four-triangle set and the role-labelled scaffold.

## Septenary scaffold

The role-labelled scaffold contains exactly twenty-eight points on radius 7.

Its repeating role structure is generated computationally and contains:

```text
12 moon-centre points
8 inter-Moon-gap points
8 intersection-positioner points
```

The independently generated four-triangle angular set and the scaffold agree
to floating-point precision.

## Generative boundary

The canonical v0.5 architecture is:

```text
MichellComposite
      |
      +-- deterministic SVG renderer
      |
      +-- machine-readable geometry exporter
      |
      +-- provenance exporter
```

No downstream component should introduce a second independent geometric
reconstruction.

Source-plate calibration, digitisation, registration, and measured source
coordinates remain outside the generative path.
