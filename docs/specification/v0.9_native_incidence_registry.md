### Core exact definitions

Earth-square vertices use:

```text
(±11/2, ±11/2)
```

Square/construction-circle junctions are sign/permutations of:

```text
(11/2, 5*sqrt(3)/2)
```

because:

```text
(5*sqrt(3)/2)^2
    = 49 - (11/2)^2
    = 75/4.
```

For incidence Moon centres, let:

```text
theta_sq = acos(11/14)
Delta_inc = acos(383/392)
beta_inc = theta_sq - Delta_inc.
```

Here `Delta_inc` is the central angle subtended by a chord of length `3/2`
on the radius-7 construction circle:

```text
cos(Delta_inc)
    = 1 - (3/2)^2 / (2*7^2)
    = 383/392.
```

Each cardinal group contributes:

```text
gamma - beta_inc
gamma
gamma + beta_inc
```

with:

```text
gamma in {0, pi/2, pi, 3*pi/2}.
```

### Method 1 exact definitions

Let:

```text
cos(alpha_1)
    = (1 - sqrt(3) + sqrt(6*sqrt(3))) / 4.
```

The seven registered local offsets in each quadrant are:

```text
0
2*alpha_1 - pi/2
pi - 3*alpha_1
pi/2 - alpha_1
alpha_1
3*alpha_1 - pi/2
pi - 2*alpha_1
```

and each is translated by:

```text
q*pi/2, q = 0,1,2,3.
```

This gives the frozen 28 semantic scaffold directions.

### Method 2 exact definitions

Let:

```text
cos(alpha_2) = 5/8.
```

Use:

```text
gamma_0 = pi/2
gamma_n = gamma_0 + n*pi/3, n = 0,...,5
k = -3,...,+3
```

and:

```text
theta(n,k) = normalize(gamma_n + k*alpha_2).
```

This gives 42 semantic marks.

Even `n` are original-triangle carriers and odd `n` are reciprocal-triangle
carriers.

No `2*pi/7`, `pi/7`, DIVISION_28 object, or exact regular-heptagram helper is
used to generate these 98 native radial points.


cannot alter exact-candidate classification.

## Exact-candidate classification

The finite registry is not searched for equality by floating-point tolerance.

Every registered candidate is certified to have Euclidean-constructible
lineage.

If Question A verifies that the exact heptagonal target has algebraic degree
3 while the admitted Euclidean closure contains only algebraic elements of
power-of-two degree over `Q`, then:

```text
exact_candidate_count = 0
```

follows theoremically for this registry.

The floating-point angles are used only after this classification to identify
the closest descriptive native feature.

## Descriptive nearest-feature rule

After the full registry is built without target input, evaluate numerical
distance to:

```text
theta_7 = 2*pi/7.
```

For radial directions, compare both target orientations:

```text
+theta_7
-theta_7
```

under circular distance.

For pairwise radial separations, compare the registered separation directly
to `theta_7`.

For undirected native lines, use the canonical line orientation in
`[0,pi/2]` and compare directly to `theta_7`.

Rank by:

```text
(absolute residual, candidate_id)
```

for deterministic tie-breaking.

The nearest candidate is descriptive only and can never be promoted to exact.
