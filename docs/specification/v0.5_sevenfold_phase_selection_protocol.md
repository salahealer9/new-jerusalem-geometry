# v0.5 sevenfold / scaffold phase-selection audit protocol

## Status

This document preregisters Phase 5F of the v0.5 full generative
New Jerusalem reconstruction.

Phase 5F addresses a remaining discrete ambiguity in the integrated
`NJG_MICHELL` construction:

```text
Which one of the four seven-point residue classes of the 28-point scaffold,
if any, is selected by the construction grammar independently of Figure 14
plate coordinates?
````

This is a model-selection audit.

It is not a scale-invariance test and does not modify the Phase 5E result.

## Existing implementation boundary

The current `NJG_MICHELL` composite uses a scaffold-derived Figure 14
candidate whose seven scaffold indices are:

```text
7, 11, 15, 19, 23, 27, 3
```

As an unordered residue class, this is:

```text
phase 3:
3, 7, 11, 15, 19, 23, 27
```

That existing implementation choice must not be treated as evidence that
phase 3 is historically or mathematically preferred.

Phase 5F therefore reconstructs all four candidates symmetrically.

## Candidate set

The complete preregistered candidate family is:

```text
phase 0:
0, 4, 8, 12, 16, 20, 24

phase 1:
1, 5, 9, 13, 17, 21, 25

phase 2:
2, 6, 10, 14, 18, 22, 26

phase 3:
3, 7, 11, 15, 19, 23, 27
```

No additional phase candidate may be introduced after evaluation begins.

No candidate may be removed because it performs poorly.

## Set identity versus cyclic origin

A seven-point phase is fundamentally a set of scaffold locations.

Its choice of starting vertex is not itself a separate phase.

For example:

```text
3, 7, 11, 15, 19, 23, 27
```

and:

```text
7, 11, 15, 19, 23, 27, 3
```

represent the same phase-3 point set with different cyclic origins.

The audit must therefore distinguish:

```text
phase selection
```

from:

```text
cyclic starting index
```

and from:

```text
heptagram traversal topology
```

These are separate choices.

## Topology boundary

Phase 5F is not a new audit of the Figure 14 edge topology.

The currently implemented seven-point star uses the already established
step-2 / `{7/2}` traversal:

```text
0, 2, 4, 6, 1, 3, 5
```

For comparisons that require edges, the same topology must be applied to all
four phase candidates.

The topology must not be changed separately for different phases.

## Two-stage audit

Phase 5F is divided into two strictly ordered stages.

### Stage A — grammar-only phase selection

Stage A evaluates all four phase candidates without consulting Figure 14
coordinate residuals.

The Stage A result must be recorded before Stage B source-coordinate
comparison is performed.

### Stage B — descriptive Figure 14 source comparison

Only after Stage A is closed may the four frozen candidates be compared with
the already existing Figure 14 calibration data.

Stage B is descriptive.

Because Figure 14 source information participated historically in development
of the current candidate, Stage B is not an independent held-out validation
and must not be represented as one.

Stage B may rank source consistency.

It may not retroactively convert a Stage A underdetermination into a
grammar-derived selection.

## Stage A admissible evidence

Stage A may use:

```text
the mathematical 28-point scaffold;
the scaffold indices;
scaffold angles;
scaffold roles;
the fourfold symmetry of the construction;
source-stated role information;
construction-grammar relations that do not encode a prior phase choice;
pure mathematical consequences of those data.
```

Source-stated Figure 14 information may be used only at the semantic level
already expressed in the audited source claims, such as the statement that
star extremities accord with three circle centres and two square-circle
junctions.

Stage A may not use source-plate coordinates or residuals.

## Stage A excluded evidence

Stage A must not use:

```text
Figure 14 source pixels;
digitised Figure 14 endpoint coordinates;
affine registration residuals;
source-to-model RMS values;
per-phase fitted transformations;
the existing phase-3 coordinates as a preferred target;
the current composite's phase choice as evidence;
Figure 14 plate-derived phase ranking.
```

The following existing grammar statuses do not count as independent
phase-selection evidence:

```text
implementation_only
hypothesis_to_test
project_result
source_calibrated_result
```

In particular, an implementation node that records the current phase-3
indices documents the implementation state; it does not prove that the
construction grammar uniquely selects phase 3.

## Source-role criterion

The audited Figure 14 source text identifies five stated endpoint roles:

```text
three circle centres
two square-circle junctions
```

The existing project reconstruction also supplies two inferred inter-Moon
gap roles to complete the seven-point candidate.

For each phase, Stage A must report independently:

```text
number of moon_centre positions
number of intersection_positioner positions
number of inter_moon_gap positions
```

The strict source-grounded comparison uses only the stated:

```text
3 Moon centres
2 intersection positions
```

The two gap roles remain project inference and must be labelled as such.

## Role-order criterion

Role counts alone may conceal a difference in cyclic structure.

Stage A must therefore also compare the complete cyclic role word of each
phase.

Two role sequences are considered equivalent if one is a cyclic rotation of
the other.

The arbitrary starting index of a phase must not create a false distinction.

A reversal may be reported separately, but reversal equivalence must not be
used to manufacture a unique phase unless the source grammar supplies an
orientation condition.

## Fourfold rotational symmetry

The audit must explicitly test the quarter-turn action on scaffold indices.

A +90 degree scaffold rotation corresponds to:

```text
index -> index + 7 mod 28
```

The expected phase orbit is:

```text
phase 0 -> phase 3
phase 3 -> phase 2
phase 2 -> phase 1
phase 1 -> phase 0
```

This relation must be tested from the generated scaffold rather than merely
asserted.

For every candidate point `p`, its quarter-turned coordinate should agree,
within floating-point tolerance, with the corresponding point at index:

```text
(index + 7) mod 28
```

If all four phases belong to one exact C4 orbit, any rotationally invariant
metric must be treated as incapable of uniquely selecting one phase.

## Radial criterion

Every selected point in every phase is expected to lie on the same
construction/scaffold circle.

Stage A must test:

```text
radius = scaffold radius
```

for all 28 candidate memberships.

This criterion is a validity check, not a selection criterion unless one or
more phases fail.

## Seven-point completeness

Each candidate must contain:

```text
7 unique scaffold indices
7 unique scaffold points
```

with no duplicated member.

Failure of this criterion would invalidate that candidate.

## Step-2 topology criterion

The same `{7/2}` step-2 traversal must be applied to each phase.

For each phase the audit should compute:

```text
7 candidate vertices
7 edges
edge-index pairs
edge lengths
perimeter of the step-2 star
```

These values are mathematical diagnostics.

No Figure 14 coordinate data are involved.

## Metric-equivalence criterion

The audit must compare the four candidate star geometries under the known
quarter-turn symmetry.

At minimum compare:

```text
sorted edge-length multiset
total star-edge length
successive angular gaps
radial distances
```

If these are identical up to numerical tolerance under rotation, they cannot
serve as a unique phase-selection rule.

No post-hoc metric may be introduced merely because it favors the currently
implemented phase.

## Cardinal-orientation criterion

A quarter-turn symmetry can only be broken by orientation-specific evidence
if such evidence is actually present in the construction grammar or primary
source claims.

Therefore Stage A must explicitly ask:

```text
Is there an admissible source or grammar statement that assigns a specific
star extremity to a named cardinal direction or otherwise distinguishes one
quarter-turn orientation?
```

If no such statement exists in the audited claim/grammar set, cardinal
orientation must not be used as a tie-breaker.

The drawing itself is not admissible for this Stage A question because that
would reintroduce plate information.

## Primary/reciprocal construction relationship

The audit may report whether any phase coincides with point sets already
generated by the primary or reciprocal sevenfold constructions.

Such correspondence is descriptive unless the grammar provides a source-based
rule selecting that construction specifically for Figure 14.

The mere fact that the current implementation uses one of those sets is not
selection evidence.

## Stage A decision rule

The Stage A outcome vocabulary is:

```text
UNIQUE_GRAMMAR_SELECTION
GRAMMAR_UNDERDETERMINED
GRAMMAR_INCONSISTENT
```

### UNIQUE_GRAMMAR_SELECTION

This result requires exactly one of the four phases to satisfy at least one
preregistered admissible construction constraint that the others fail.

The discriminating condition must be traceable to source-grounded or purely
mathematical grammar information that does not encode the existing phase
choice.

### GRAMMAR_UNDERDETERMINED

This result is required if two or more phases remain compatible with every
admissible Stage A condition.

No residual ranking or aesthetic preference may then be used to relabel the
result as unique.

### GRAMMAR_INCONSISTENT

This result is required if no phase satisfies the admissible grammar
conditions.

## Preregistered expected Stage A result

The expected Stage A result is:

```text
GRAMMAR_UNDERDETERMINED
```

with all four phases expected to remain members of one quarter-turn symmetry
orbit.

The anticipated reason is that each residue class appears to carry the same
role composition and the same intrinsic seven-point geometry up to C4
rotation.

This expectation is frozen before the formal audit is executed.

## Stage B source-coordinate comparison

After the Stage A result has been written to an audit artifact, Stage B may
compare all four phases with the existing Figure 14 calibrated endpoint data.

No phase may be omitted.

No candidate geometry may be moved or altered to improve its residual.

## Registration freeze

Stage B must use the already established Figure 14 source registration.

It must not:

```text
refit a separate affine registration for each phase;
change digitised endpoints;
change source landmarks;
change the scaffold geometry;
change the 28-point construction;
change the star topology;
introduce a phase-specific rotation fitted from the source plate.
```

The purpose is comparison under the already frozen source coordinate system.

## Correspondence handling

A phase set has no privileged cyclic starting point.

Therefore endpoint comparison must not penalize a candidate solely because
its tuple begins at a different member of the same seven-point set.

The Stage B implementation must define its correspondence rule before
computing residuals.

The preferred registered rule is:

```text
evaluate the seven cyclic starting positions;
evaluate both traversal orientations where geometrically appropriate;
preserve the fixed seven-point cyclic structure;
take the minimum RMS over those purely combinatorial correspondences.
```

This gives at most:

```text
7 x 2 = 14
```

correspondences per phase.

No continuous geometric transformation may be fitted during this step.

If the existing source-calibration API already fixes semantic endpoint
correspondence more strongly than this, that stronger fixed correspondence
must be documented before residuals are evaluated.

## Stage B reported quantities

For every phase report at minimum:

```text
phase id
scaffold indices
role counts
best allowed cyclic/orientation correspondence
RMS endpoint residual
maximum endpoint residual
mean endpoint residual
rank among four phases
```

Where useful, normalized residuals may also be reported relative to:

```text
construction-circle radius
existing affine leave-one-out uncertainty
```

but no significance claim follows automatically.

## Stage B interpretation

Possible Stage B statements include:

```text
phase X is most consistent with the existing Figure 14 calibration
under the frozen comparison rule;
```

or:

```text
the four phases are not meaningfully distinguishable at the resolution of
the calibration.
```

Stage B may not establish:

```text
grammar-derived uniqueness;
independent prediction;
held-out validation;
historical necessity.
```

## Existing phase-3 selection and circularity control

The current composite already implements phase 3.

The audit must therefore explicitly record that Figure 14 source material
participated in the historical development of that choice.

If phase 3 ranks best in Stage B, this is a source-consistency result and not
independent confirmation.

If phase 3 does not rank best, the discrepancy must be reported rather than
hidden or resolved by refitting.

The Phase 5F audit itself must not silently rewrite the frozen v0.4/v0.5
composite in response.

## Builder freeze

Throughout Phase 5F:

```text
build_michell_composite(unit=1.0)
```

remains unchanged.

Phase candidates are constructed in the audit layer from the supplied
28-point scaffold.

No candidate result is fed back into the builder during the audit.

## Scale

Phase selection is dimensionless.

The canonical Phase 5F audit uses:

```text
unit = 1.0
```

The Phase 5E audit already established scale covariance of the integrated
construction.

Phase 5F therefore does not repeat the five-scale test unless a defect is
found that specifically calls scale independence into question.

## Numerical tolerance

For purely mathematical rotational and metric comparisons:

```text
relative tolerance = 1e-12
absolute tolerance = 1e-12
```

Source-coordinate residual calculations use the numerical conventions already
established by the Figure 14 calibration pipeline.

Those conventions must not be loosened after phase results are seen.

The artifact should contain separate top-level sections:


so that grammar-only findings remain visibly separated from source-coordinate
comparison.

## Determinism

Repeated execution of the Phase 5F audit with unchanged inputs must produce
byte-identical JSON.

## Interpretation boundary

A Stage A result of:

```text
GRAMMAR_UNDERDETERMINED
```

would be scientifically meaningful.

It would show that the 28-point construction supplies a family of four
symmetry-related seven-point candidates but does not, by itself, determine the
orientation used by the current Figure 14 reconstruction.

That is not a failure of the geometric reconstruction.

It is identification of a genuine remaining degree of freedom.

Likewise, a Stage B preference for phase 3 would establish only that the
existing phase-3 choice is more consistent with the already consulted Figure
14 source calibration under the frozen comparison rule.

## Software-version boundary

The project package version remains:

```text
0.4.0
```

during Phase 5F.

No version bump occurs until the final v0.5 integration checkpoint.
