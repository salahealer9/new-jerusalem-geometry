## External mathematical precedent

A modern mathematical reference for exact heptagon constructions by angle
trisection is:

```text
Helmut Ruhland,
"Unified constructions of the regular Heptagon and Triskaidecagon",
arXiv:2505.05673.
```

That paper records an Adlaj-type heptagon construction using the unit complex
quantity

```text
zeta = (1 - 3*sqrt(3)*i)/(2*sqrt(7))
```

and states that determining its third root is equivalent to trisecting the
angle

```text
-theta = -atan(3*sqrt(3))
```

up to orientation convention.

This literature observation is recorded for provenance. The executable v0.9
candidate below is derived directly from the frozen Phase 9B cubic and does
not use the paper's final heptagon coordinates as an input.

No historical claim about Michell or Sommerville follows from this external
mathematical precedent.

## Registered extension class

Exactly one new non-Euclidean operation is permitted:

```text
TRISECT_ANGLE
```

Input:

```text
one already-Euclidean-constructible angle Theta
with 0 < Theta < pi/2
```

Output:

```text
phi = Theta/3
with 0 < phi < pi/6
```

Only the acute one-third branch is admissible.

Operation count:

```text
TRISECT_ANGLE calls = exactly 1
```

All other steps before and after the trisection must be ordinary Euclidean
straightedge-and-compass constructions from constructible lengths, points,
lines, circles, parallels, perpendiculars, midpoints, similar triangles,
geometric means, and line/circle or circle/circle intersections.

No second cubic-capable operation is allowed.

The project does not require Phase 9D to choose a physical realization of
`TRISECT_ANGLE`. A marked-ruler/neusis or origami realization would be a
separate implementation layer.

## Frozen cubic reconstruction

Define:

```text
z = (2*sqrt(7)/3)*cos(phi)

y = z - 1/3.
```

The required derivation is fixed before execution.

Using:

```text
4*cos(phi)^3 - 3*cos(phi)
    = cos(3*phi)
    = 1/(2*sqrt(7)),
```

the implementation must verify:

```text
z^3 - (7/3)*z - 7/27 = 0.
```

Then substitution:

```text
y = z - 1/3
```

must mechanically give:

```text
y^3 + y^2 - 2*y - 1 = 0.
```

This is exactly the target cubic frozen in Phase 9B.

No numerical root fitting is permitted.

## Root-selection rule

The correct real root is selected by an interval fixed before execution.

Because:

```text
0 < Theta < pi/2
```

the acute trisection gives:

```text
0 < phi < pi/6.
```

Hence:

```text
sqrt(3)/2 < cos(phi) < 1.
```

Therefore:

```text
(sqrt(21)-1)/3
    < y
    < (2*sqrt(7)-1)/3.
```

The implementation must verify exactly that this interval lies inside:

```text
1 < y < 2.
```

For:

```text
f(y) = y^3 + y^2 - 2*y - 1
```

the derivative is:

```text
f'(y) = 3*y^2 + 2*y - 2.
```

The implementation must verify:

```text
f'(y) > 0
for 1 <= y <= 2.
```

Therefore the cubic has at most one root in `(1,2)`.

Since Phase 9B already identifies the exact sevenfold quantity

```text
y_7 = 2*cos(2*pi/7)
```

as a root in `(1,2)`, the constructed `y` must equal `y_7`.

The interval rule, not a nearest-root numerical choice, fixes the branch.

## Exact heptagon extraction

After `y` has been constructed, define:

```text
c = y/2.
```

On a radius-`R` circle centred at the origin, construct the vertical line:

```text
x = R*c.
```

Its upper intersection `P1` with the circle has:

```text
P1 = (
    R*c,
    R*sqrt(1-c^2)
)
```

and therefore polar angle:

```text
2*pi/7.
```

Take:

```text
P0 = (R,0).
```

The chord:

```text
s = distance(P0,P1)
```

is then an exact regular-heptagon side.

Use that constructed chord length as a compass step on the same circle to
generate the remaining vertices.

This stepping uses only ordinary circle/circle intersections after the one
trisection.
