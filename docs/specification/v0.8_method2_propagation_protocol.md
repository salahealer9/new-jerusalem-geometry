## Research question

Given the frozen local Method 2 step from Figure 194, what deterministic
21-point and 42-point circumference sets follow from Michell's stated
extensions, and how nonuniform are those sets relative to exact regular
21-fold and 42-fold angular divisions?

## Primary-source chain

Figure 194 Method 2 states the following sequence:

```text
d. one equilateral triangle + one midpoint arc
   -> seven divisions

e. corresponding arcs from the other two triangle vertices
   -> twenty-one divisions

f. a reciprocal triangle is added, producing a hexagon
   -> forty-two divisions
```

The source calls these divisions approximate/virtual rather than exact.

The present protocol does not digitize the printed plate and does not fit
coordinates to it.

## Frozen local Method 2 step

Phase 8A derived and Phase 8C implemented the local Method 2 step as:

```text
alpha_2 = acos(5/8)
```

Phase 8E must import/reuse the frozen Phase 8C implementation rather than
rederive a numerically different Method 2 angle.

No new local step parameter is permitted.

## Coordinate convention

The construction circle has unit radius for the propagation audit.

The global phase is fixed as a coordinate convention only:

```text
gamma_0 = pi/2
```

so the first equilateral-triangle carrier is at the top of the circle.

All reported gap and regularity metrics are rotation invariant. The choice
`gamma_0 = pi/2` is not a fitted parameter and must not be adjusted.

Angles are normalized to the half-open interval:

```text
[0, 2*pi)
```

## Local seven-mark completion

Figure 194 panel d supplies a carrier triangle vertex and the two adjacent
arc-circle intersections determined by `alpha_2`.

To turn that local step into a complete deterministic seven-mark division,
the project preregisters the following operational completion:

```text
k in {-3, -2, -1, 0, 1, 2, 3}

theta(gamma, k)
    = normalize(gamma + k*alpha_2)
```

where:

```text
k = 0
```

is the carrier triangle vertex and

```text
k = -1, +1
```

are the two source-described arc-circle intersections.

The remaining `k = +/-2, +/-3` points continue the same fixed compass/angular
step around the circumference.

This repeated-step completion is a project operationalization of Michell's
"seven virtually equal parts"; it is not represented as an additional
explicit formula stated by Michell.

No alternate seven-mark completion may be selected after seeing the 21-point
or 42-point results.

## Twenty-one-point construction

The original equilateral triangle has three carrier phases:

```text
gamma_j
    = gamma_0 + j*(2*pi/3)

j in {0, 1, 2}
```

For each carrier, generate the seven semantic marks:

```text
theta(j, k)
    = normalize(gamma_j + k*alpha_2)

k in {-3, -2, -1, 0, 1, 2, 3}
```

The canonical 21-point set therefore contains exactly the labelled semantic
pairs:

```text
(j, k)

j = 0, 1, 2
k = -3, -2, -1, 0, 1, 2, 3
```

No proximity-based deduplication is allowed.

A pairwise angular-separation check at the registered implementation
tolerance may verify that no two semantic labels numerically collide.

## Reciprocal triangle and forty-two-point construction

The reciprocal equilateral triangle is preregistered as the original triangle
rotated by:

```text
pi/3
```

Together the two triangles form six regular hexagonal carrier phases:

```text
gamma_n
    = gamma_0 + n*(pi/3)

n in {0, 1, 2, 3, 4, 5}
```

Carrier parity identifies provenance:

```text
even n:
    original equilateral triangle

odd n:
    reciprocal equilateral triangle
```

For each of the six carriers generate:

```text
theta(n, k)
    = normalize(gamma_n + k*alpha_2)

k in {-3, -2, -1, 0, 1, 2, 3}
```

The canonical 42-point set therefore contains exactly the semantic pairs:

```text
(n, k)

n = 0, 1, 2, 3, 4, 5
k = -3, -2, -1, 0, 1, 2, 3
```

No proximity-based deduplication is allowed.

## Registered implementation tolerance

The following tolerance is used only for identity/collision checks:

```text
identity_tolerance_radians = 1e-12
```

It is not a goodness-of-fit threshold and is not used to classify historical
accuracy.

It may be used only for:

- checking that all 21 semantic marks are numerically distinct;
- checking that all 42 semantic marks are numerically distinct;
- checking registered rotational/subset identities;
- checking total cyclic-gap closure to `2*pi`.

Angular residuals and rankings use raw computed values without thresholding.

## Registered cyclic-gap calculation

For each point set `N in {21, 42}`:

1. normalize every angle to `[0, 2*pi)`;
2. sort all angles in ascending numeric order;
3. calculate each consecutive angular gap;
4. include the wraparound gap from the final point back to the first point;
5. preserve the semantic label at each gap's start and end.

Thus exactly `N` cyclic gaps must be emitted.

The exact regular reference gap is:

```text
regular_gap_N = 2*pi/N
```

For every gap `g_i`, calculate:

```text
signed_gap_residual_i
    = g_i - regular_gap_N

absolute_gap_residual_i
    = abs(signed_gap_residual_i)
```

No gap may be rounded before residual calculation.

## Registered aggregate nonuniformity metrics

For each `N in {21, 42}`, calculate:

```text
minimum_gap
maximum_gap
mean_gap

gap_range
    = maximum_gap - minimum_gap

rms_gap_residual
    = sqrt(
        mean(
            signed_gap_residual_i^2
        )
      )

maximum_absolute_gap_residual
    = max(
        absolute_gap_residual_i
      )

normalized_rms_gap_residual
    = rms_gap_residual / regular_gap_N
```

The arithmetic mean of all cyclic gaps must also be checked against:

```text
2*pi/N
```

within the registered implementation tolerance.

No metric is preregistered as a success/failure threshold.

## Registered regularity report

For each `N in {21, 42}`, report:

```text
numerically_regular_at_identity_tolerance
```

defined as:

```text
maximum_absolute_gap_residual
    <= identity_tolerance_radians
```

This field is a numerical implementation classification only.

The raw residuals and aggregate metrics remain authoritative.

## Registered 21-versus-42 descriptive comparison

Calculate:

```text
rms_ratio_42_over_21
    = rms_gap_residual_42
      / rms_gap_residual_21

max_abs_ratio_42_over_21
    = maximum_absolute_gap_residual_42
      / maximum_absolute_gap_residual_21
```

If either denominator is exactly zero, report the corresponding ratio as
undefined rather than regularizing it.

Also report the raw ordering of the two constructions by:

```text
rms_gap_residual
maximum_absolute_gap_residual
```

with exact floating-point ties reported as `TIE`.

No direction of improvement is preregistered.

## Stopping rule

Phase 8E terminates with:

```text
METHOD2_7_21_42_PROPAGATION_COMPLETE
```

if and only if:

- the frozen Phase 8C Method 2 step is reused without alteration;
- the local seven-mark completion follows the preregistered `k=-3..3` rule;
- exactly three original triangle carriers generate 21 semantic marks;
- exactly six hexagonal carriers generate 42 semantic marks;
- S1 through S5 are evaluated exactly as preregistered;
- every cyclic gap and every registered nonuniformity metric is emitted;
- the 21-versus-42 descriptive comparison is emitted;
- all zero-degree-of-freedom conditions remain satisfied;
- deterministic serialization tests pass.

The stopping status does not depend on:

- whether either set is numerically regular;
- whether 42 is more regular than 21;
- the number or sizes of observed gap classes;
- any agreement with a later source plate;
- any historical interpretation.
