## Research question

Given Michell's two source-described approximate Figure 194 constructions,
what are their local sevenfold angular errors relative to the exact regular
heptagonal step, and what simple relationships hold between those two errors?

This protocol concerns only the local sevenfold step.

It does not test the 21-point, 28-point, 42-point, Figure 14, lunar-circle,
outer-wall, metrological, or symbolic consequences.

## Source and evidential boundary

Method 1 is the already implemented Figure 194 construction used in the
existing `7 -> 14 -> 28` project chain.

Method 2 is the Phase 8A source-registered equilateral-triangle / midpoint-arc
construction.

The analytic Method 2 identity

```text
alpha_2 = arccos(5/8)
```

is a project derivation already registered as `SEVEN-014`.

The exact regular heptagonal reference is

```text
alpha_exact = 2*pi/7
```

using Euclidean `pi`.

No numerical decimal value of any of these quantities is preregistered here.

## Frozen numerical inputs

### Method 1


The implementation shall be evaluated at unit scale `1.0`.

### Method 2

```text

```

The Method 2 comparison implementation may encode this exact analytic identity
or reproduce it from the source-described chord geometry, but the numerical
result must agree with the identity to absolute tolerance `1e-15` radians.

That tolerance tests implementation identity only. It is not an evidential
success threshold.

## Primary metrics

For each method `i in {1, 2}`, calculate:

```text
signed_residual_i =
    alpha_i - alpha_exact

absolute_residual_i =
    abs(signed_residual_i)

relative_residual_i =
    signed_residual_i / alpha_exact

percent_residual_i =
    100 * relative_residual_i

absolute_percent_residual_i =
    abs(percent_residual_i)

seven_step_closure_i =
    7*alpha_i - 2*pi
```

All calculations are performed in radians internally.

Degree representations may be emitted for readability only and must be direct
unit conversions of the radian quantities.

No prediction may be rounded before a residual is calculated.

## Registered relationship tests

The implementation shall calculate and report the following descriptive
relationships.

### R1 — bracketing

```text
alpha_2 < alpha_exact < alpha_1
```

Report only `true` or `false`.

This is not a preregistered success criterion and no outcome is assumed.

### R2 — opposite signed errors

```text
sign(signed_residual_1)
!=
sign(signed_residual_2)
```

Zero residual is treated as its own case rather than positive or negative.

Report only the observed relationship.

### R3 — absolute-accuracy ordering

Rank Method 1 and Method 2 by ascending raw `absolute_residual`.

No tolerance-based tie-breaking is allowed.

If the raw floating-point values are exactly equal, report `TIE`.

### R4 — absolute-error ratio

Calculate:

```text
absolute_residual_2
/
absolute_residual_1
```

The ratio is descriptive only.

If `absolute_residual_1 == 0`, the ratio must be reported as undefined rather
than regularized.

### R5 — arithmetic midpoint

Calculate:

```text
alpha_mid =
    (alpha_1 + alpha_2)/2

midpoint_signed_residual =
    alpha_mid - alpha_exact

midpoint_absolute_residual =
    abs(midpoint_signed_residual)
```

This is explicitly exploratory/descriptive.

It must not be represented as:

- a third Michell construction;
- an intended averaging scheme;
- a tuned correction;
- evidence of deliberate compensation;
- a superior historical method.

No optimized weighting of Method 1 and Method 2 is permitted.

## Prohibited calculations and interpretations

Phase 8C execution under this protocol shall not:

- fit any continuous parameter;
- choose between alternate Method 2 constructions after seeing residuals;
- alter Method 1;
- optimize a weighted combination of the methods;
- infer a tolerance from the observed errors;
- use Figure 14 or any plate calibration;
- construct or evaluate the 21-point or 42-point extensions;
- compare Method 2 against the 28-point scaffold;
- calculate a p-value or statistical significance;
- introduce an aggregate goodness-of-fit score;
- treat a bracketing result as evidence of intention;
- treat the midpoint as a source-described construction;
- claim physical, archaeological, astronomical, or historical validation from
  the numerical comparison.

## Stopping rule

Phase 8C terminates with:

```text
DUAL_METHOD_LOCAL_COMPARISON_COMPLETE
```

if and only if:

- the frozen Method 1 step is read without alteration;
- Method 2 reproduces `acos(5/8)` to the registered implementation tolerance;
- all primary metrics are emitted for both methods;
- R1 through R5 are evaluated exactly as registered;
- all zero-degree-of-freedom conditions remain satisfied;
- deterministic serialization tests pass.

The stopping status does not depend on whether either method is closer, whether
the methods bracket the exact value, or whether the midpoint improves the
residual.
