# v0.6 historical metrology registry schema

## Purpose

`docs/sources/v0.6_metrology_registry.csv` is the frozen source-and-provenance
inventory for the v0.6 historical metrology audit.

It is intentionally created before any v0.6 prediction or residual
calculation.

The registry contains historical/source quantities and classifications only.
It must not contain values fitted from v0.6 residuals.

## Columns

### `record_id`

Stable unique identifier.

Families presently use prefixes:

- `CORE`
- `SCALE`
- `UNIT`
- `WALL12`
- `SOMM`
- `DECAGON`

### `family`

Broad source/geometry family.

Allowed values:

- `earth_moon_core`
- `new_jerusalem_scale`
- `metrological_unit`
- `figure12_wall`
- `sommerville_wall`
- `sommerville_decagon`

### `quantity_name`

Stable semantic name for the historical quantity.

### `record_type`

Allowed values:

- `dimension`
- `unit_definition`
- `ratio`
- `conventional_relation`
- `tolerance`

### `book`

Primary Michell source in which the statement is being audited.

Allowed values:

- `City of Revelation`
- `How the World Is Made`

### `printed_page`

Printed page number in the cited edition.

### `pdf_page`

PDF page number used by the project source copy.

### `figure`

Figure number where applicable; blank otherwise.

### `source_status`

How the source presents the quantity.

Allowed values:

- `stated_exact`
- `stated_approximate`
- `conventional_exact`
- `reported_approximate`

`reported_approximate` is used where Michell reports another person's
approximate numerical analysis.

### `attribution_class`

Allowed values frozen by the v0.6 plan:

- `michell_stated`
- `michell_adopts_external`
- `michell_reports_other`

`project_derived` is reserved for later derived-output tables and must not
appear in this historical-source registry.

### `attributed_person_or_source`

Named external person/work where Michell attributes the quantity.

Blank when the statement is simply Michell's own exposition.

### `source_value`

Primary numerical value as stated in the source.

For a pure ratio record this is the numerator.

### `source_unit`

Unit attached to `source_value`.

Canonical registry unit labels currently include:

- `mile`
- `foot`
- `inch`
- `megalithic_yard`
- `sumerian_foot`
- `old_english_foot`
- `current_foot`
- `square_foot`
- `dimensionless`

### `secondary_value`

Optional second numerical value belonging to the same source relation.

Examples:

- `13.2 inch = 1.1 English foot`;
- old-English/current-foot ratio `12:11`;
- decagon ratio `176:175`.

### `secondary_unit`

Unit attached to `secondary_value`.

### `relation`

Machine-readable-enough textual relation specifying what the numerical fields
mean.

This field records source arithmetic; it is not a fitted model expression.

### `pi_convention`

Allowed values:

- blank
- `euclidean`
- `22/7`

No result exact only under `22/7` may later be described as Euclidean exact.

### `prediction_status`

Allowed values frozen by the v0.6 plan:

- `construction_input`
- `unit_definition`
- `construction_identity`
- `development_used_target`
- `frozen_unused_target`
- `descriptive_correspondence`
- `not_evaluable_from_v0_5`

The registry must err toward the weaker category when provenance is
ambiguous.

### `v0_5_geometry_reference`

The frozen v0.5 object, role, or geometric quantity needed to evaluate the
claim.

Blank where the record is purely a unit/tolerance definition.

### `previously_used_in_development`

Boolean `true` / `false`.

This means the historical target was available to and used in development,
selection, or assessment of the relevant frozen model.

It is not the same as merely having read the source.

### `evaluable_from_v0_5`

Boolean `true` / `false`.

`false` means v0.6 must not extend the geometry merely to make the claim
testable.

### `notes`

Concise provenance or interpretation note.

## Important classification rules

### Inputs are not predictions

The Earth/Moon dimensions and scale relations that parameterize the
construction are `construction_input` or `unit_definition`.

### Source arithmetic is not a prediction

For example, a perimeter obtained by multiplying a source-imposed mean side by
12 is a `construction_identity`.

### Development-used historical targets are retrospective

The Figure 12 wall quantities and the later Sommerville wall values were
available during development/assessment of the preferred wall reconstruction.

They therefore remain `development_used_target` where they are direct
numerical targets.

A close residual later in v0.6 must not upgrade them to
`frozen_unused_target`.

### Unmodelled source geometry remains unmodelled

The later Sommerville decagon radii are registered because they occur in the
same historical dimensional discussion, but the signed v0.5 composite does
not contain the required decagon object.

They are therefore registered as `not_evaluable_from_v0_5`.

## Mutation rule

Once Phase 6A is frozen, a record may not be removed because its eventual
numerical result is inconvenient.

Corrections to transcription or source attribution must be documented as
explicit provenance corrections, not silent rewrites.
