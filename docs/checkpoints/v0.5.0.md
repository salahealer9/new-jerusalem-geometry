Date: 2026-08-07

## Checkpoint purpose

v0.5.0 is the full generative reconstruction checkpoint for the audited
New Jerusalem geometry.

The checkpoint integrates the previously established Euclidean construction
components into one deterministic, machine-readable, provenance-linked
reconstruction while preserving the distinction between primary-source
claims, project derivations, implementation choices, and downstream
source-calibration comparisons.

## Evidential boundary

v0.5.0 does not claim that every reconstructed feature is uniquely compelled
by Michell's prose.

In particular:

- the preferred polar-pivot wall is a source-constrained project
  reconstruction;
- the Figure 14 `{7/2}` topology was selected using earlier plate tracing;
- the construction grammar alone does not uniquely select one of the four
  C4-related sevenfold phases;
- Figure 14 strongly favors phase 3 only in the explicitly downstream,
  non-independent no-refit source-consistency comparison.

These distinctions remain part of the checkpoint and must not be collapsed
in later summaries.
