## Exact sevenfold boundary retained from v0.9

The exact regular-heptagon target satisfies:

```text
y = 2*cos(2*pi/7)

y^3 + y^2 - 2*y - 1 = 0
```

The irreducible cubic target is excluded from the frozen ordinary
straightedge-and-compass closure.

The project then preregistered exactly one cubic-capable operation,
`TRISECT_ANGLE`, and confirmed that one such operation is sufficient within
the frozen project model.

This is a project mathematical result and is not attributed to Michell,
Sommerville, Plato, or an ancient source.

```text

```

or intended Michell's numerical interpretation.
