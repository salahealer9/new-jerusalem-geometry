# v0.2.0 Figure 14 source-calibration checkpoint

## Release boundary

This is a signed Git checkpoint for the private
`new-jerusalem-geometry` repository.

It is not a GitHub Release and is not a Zenodo publication.

Documentation baseline before this checkpoint:

```text
66ae351c9216269026cfe028103e09e913f16381
````

## Scope

Version `v0.2.0` completes the direct source-plate calibration of John
Michell's Figure 14 seven-pointed star.

The checkpoint adds:

* source-page provenance and deterministic rendering metadata;
* three independent 31-landmark digitisation passes;
* quality control for 93 landmark observations;
* documented junction relabelling;
* documented Moon-centre and endpoint correspondence resolution;
* similarity, affine, and projective registration comparison;
* affine-registered source landmarks;
* regular seven-vertex endpoint fitting;
* three independent near-endpoint line-tracing passes;
* promotion of all 42 ray samples with deterministic hashes;
* correction of the canonical Figure 14 topology from provisional
  `{7/3}` to source-supported `{7/2}`;
* regenerated Figure 14 analysis and SVG outputs;
* consolidated calibration documentation.

## Principal result

The seven calibrated endpoints form a near-regular radius-7 vertex set.

A free regular seven-vertex fit gives:

* centre displacement: 0.011776687 normalized units;
* radius: 7.010785783 normalized units;
* RMS residual: 0.017951284 normalized units;
* maximum residual: 0.025103754 normalized units;
* angular RMS: 0.118418906 degrees.

Endpoint geometry alone cannot distinguish `{7/2}` from `{7/3}`.
The printed topology was therefore audited independently from the two
near-endpoint stroke directions.

The topology audit gives:

| Connection |          Angular RMS |     Maximum residual | Endpoint/pass wins |
| ---------- | -------------------: | -------------------: | -----------------: |
| `{7/2}`  |  1.248033670 degrees |  2.765953418 degrees |              21/21 |
| `{7/3}`  | 24.993300526 degrees | 27.188061375 degrees |               0/21 |
| perimeter  | 26.476050606 degrees | 28.615104636 degrees |               0/21 |

The canonical Figure 14 topology is consequently `{7/2}`, with traversal:

```text
0, 2, 4, 6, 1, 3, 5
```

## Historical correction

The signed `v0.1.0` checkpoint recorded the project's provisional
`{7/3}` reconstruction.

That historical state remains documented. Version `v0.2.0` supersedes the
interpretation on the basis of direct repeated source-plate measurements,
rather than silently rewriting the earlier checkpoint.

## Interpretation boundary

This checkpoint supports a calibrated geometric reconstruction of the printed
Figure 14 plate.

It does not establish that the printed diagram is an exact Euclidean
construction, nor does it treat later symbolic or interpretive claims as
geometric evidence.
