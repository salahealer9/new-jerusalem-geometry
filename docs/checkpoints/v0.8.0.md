## Primary source result

Figure 194 describes two close approximations to sevenfold circle division.

The source states that Method 1 is better than one part in one thousand.

Method 2 is reconstructed from:

```text
equilateral triangle
+
vertex-centred arc through the midpoints of the adjacent triangle sides
```

giving the project-derived identity:

```text
alpha_2 = acos(5/8)
```

The source then extends Method 2:

```text
three triangle-vertex arcs -> 21 divisions
reciprocal triangle        -> 42 divisions
```

## Post-result exact symbolic explanation

After the Phase 8E numerical result, the gap structure was recognized and then
verified in a separately labelled post-result explanatory audit.

Define:

```text
delta = 2*pi/7 - alpha_2
```

Then:

```text
21 points:
15 gaps = g_21 + 2*delta
 6 gaps = g_21 - 5*delta

RMS_21   = sqrt(10)*delta
MAX_21   = 5*delta
RANGE_21 = 7*delta
```

and:

```text
42 points:
36 gaps = g_42 + delta
 6 gaps = g_42 - 6*delta

RMS_42   = sqrt(6)*delta
MAX_42   = 6*delta
RANGE_42 = 7*delta
```

Therefore:

```text
RMS_42 / RMS_21 = sqrt(3/5)
MAX_42 / MAX_21 = 6/5
RANGE_42 / RANGE_21 = 1

normalized_RMS_42 / normalized_RMS_21
    = 2*sqrt(3/5)
```

and:

```text
RANGE_21
= RANGE_42
= 7*delta
= abs(7*alpha_2 - 2*pi)
```

The symbolic identities were not preregistered predictions. Their evidential
status is explicitly:

```text
post-result explanatory derivation
```

## Reciprocal-stage interpretation

The reciprocal 42-point extension reduces raw RMS angular error:

```text
sqrt(10)*delta -> sqrt(6)*delta
```

while increasing the worst individual residual:

```text
5*delta -> 6*delta
```

and increasing normalized RMS because the regular reference gap is halved.

Accordingly, the 42-point stage is not assigned a single unqualified label
such as "more regular" or "less regular".
