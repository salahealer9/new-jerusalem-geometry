## Frozen-validation boundary

The integrated predictor was frozen before validation at commit:

```text
43096326d5c1862fc7e33f9d90eb1df861c3b642
```

The validation protocol was committed before the new residual metrics were
calculated.

The validation prohibits post-freeze fitting of:

* translation;
* rotation;
* phase;
* scale;
* affine or projective transformations;
* Moon positions;
* wall orientations or supports;
* heptagram vertex coordinates;
* vertex permutations or cyclic reassignment.

Calibration information therefore flows only into the downstream validation
layer and never back into the frozen `NJG_MICHELL` predictor.

Because Figures 12 and 14 informed earlier model-development stages, the
analysis is described as frozen forward validation with no refitting rather
than as a statistically independent hold-out experiment.

## Construction-grammar evidence boundary

The dependency grammar distinguishes:

* source-stated exact relations;
* source-stated approximate relations;
* historical numerical conventions;
* mathematical project derivations;
* project reconstructions;
* project inferences;
* implementation-only dependencies;
* hypotheses retained for testing;
* downstream project validation results.

Computational dependency is not treated as proof of historical construction
order.
